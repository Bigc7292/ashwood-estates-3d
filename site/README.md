# Ashwood 3D shareable site

Static site for Vercel. Root directory: `site/`, no build step, framework "Other".
Pages are snapshots copied from `production-line/artifacts/2026-11-10b/ (exterior, first floor, roof floor, progress) and production-line/artifacts/2026-11-10/ (ground floor, pictures)` (self-contained single files, no external requests).
`index.html` links the six viewers. Concept visualisation, not survey-verified, not construction-ready, not certified CAD.
